# 🐦 Desktop Bird — Pocket Bird Enhanced Edition

A delightful, animated desktop companion that perches, sings, hops, flies, wears stylish hats, chases your mouse cursor, and sits directly on top of website text lines and horizontal dividers on your display!

*Based on [Pocket-Bird](https://github.com/matthew-r-callaghan/Pocket-Bird) by Matthew Callaghan.*

---

## ✨ Features

- 🎨 **34 Real-World Bird Species** (Eastern Bluebird, Shima Enaga, Red Cardinal, Tufted Titmouse, European Robin, American Goldfinch, Pidgey, and more!)
- 🎩 **12 Wearable Hats** (Top Hat, Viking Helmet, Cowboy Hat, Fez, Wizard Hat, Baseball Cap, Beanie, Sun Hat, Straw Hat, Cordovan Hat)
- 🪶 **Authentic Wing-Flapping Animations**
- 📜 **Display Text & Line Perching Engine** (sits on website text lines, horizontal dividers `__________________________`, code blocks, and taskbars)
- 🔊 **Synthesised Birdsong Audio** (frequency-swept chirps & melodies)
- ⚙️ **Catppuccin Dark UI** (Species Selector, Hat Closet, Settings, System Tray)

---

## 🚀 How to Run

```bash
cd bird
python main.py
```
