# 🐾 Desktop Pet

A collection of interactive desktop pets that live on your screen.

## 🐱 Cat

An animated desktop cat with:
- Idle, walking, sleeping, happy, and angry states
- Realistic synthesised sounds (meow, purr, happy chirp, angry yowl)
- Drag to move, click to pet, double-click for a speech bubble
- System tray controls and settings panel
